# 风声 · 谍战桌游（网页版）

以经典国产谍战桌游《风声》（The Message）为蓝本的单机网页游戏：你 + 3~7 名 AI，
三大阵营身份暗置对抗。零依赖，单文件实现。

## 怎么玩

直接用浏览器打开 `index.html` 即可（无需服务器、无需联网）。

## 规则概要

### 阵营与胜利条件

| 阵营 | 胜利条件 |
|------|----------|
| 潜伏战线 | 任意一名潜伏玩家集齐 **3 张红色情报** → 全体潜伏获胜 |
| 军情处 | 任意一名军情玩家集齐 **3 张蓝色情报** → 全体军情获胜 |
| 打酱油 | 完成自己身份牌上的**机密任务** → 单独获胜 |

任何玩家收到 **3 张黑色情报**（假情报）立即出局，亮出身份并弃置所有牌。

基础牌库含**双色情报**（红黑×3、蓝黑×3，黑名单版规则）：同时计入两种
颜色；一张牌同时凑满制胜与三张黑时，**先判死亡、不能获胜**（官方裁定）。

**绝密任务印在角色牌上**（黑名单版规则）：身份为打酱油时，胜利条件即你
角色自带的任务（情报贩子/殉道者/收藏家/双面间谍/纵火狂/劫收专员/完美中立
七种，按角色主题分配，详见游戏内百科）。

### 回合流程

1. **摸牌**：摸两张牌（起手三张）
2. **出牌阶段（一）**：可使用【烧毁】【试探】【锁定】等功能牌
3. **传递情报**：必须从手牌选一张作为情报传出，传递方式由牌右上角印章决定：
   （传完后还有**出牌阶段（二）**）
   - **直达**：面朝下直接交给任意玩家，对方可接收或退回（退回则自己收下）
   - **密电**：面朝下沿所选方向从邻座依次传递，每人可接收或传给下家
   - **文本**：面朝上依次传递
   - 无人接收时由传出者自己收下

### 功能牌

| 牌 | 效果 |
|----|------|
| 锁定 | 指定一名玩家，其必须接收本次情报（出牌阶段一或宣告时用，优先于调虎离山） |
| 调虎离山 | 指定一名玩家，其不能接收本次情报 |
| 退回 | 情报到你面前时，反方向继续传递 |
| 截获 | 宣告时直接拉走情报，或他人即将收下时抢走（后发先至） |
| 破译 | 偷看传到你面前的暗置情报 |
| 调包 | 用一张手牌替换传递中的情报，原情报收入你的手牌 |
| 烧毁 | 出牌阶段烧掉任意玩家情报区的一张黑色情报 |
| 试探 | 指定一名玩家按真实身份执行牌上指令（暴露身份线索） |
| 真伪莫辨 | 每名存活玩家从牌库随机分得一张情报，必须接收 |
| 识破 | 抵销最新一张功能牌的效果；识破亦可被识破（连锁）。传递本身与角色技能不可被识破 |
| 平信 | 无功能，仅作情报 |

传递分三个响应窗口（黑名单版规则）：**宣告时**（锁定/调虎离山/截获）→
**到达面前时**（破译/退回/调包）→ **决定接收时**（不可用牌）。

### 角色技能

每局随机分配 16 个角色之一，每个座位有公开的谍报代号（夜莺、灰鸽……）：

- **公开角色**（开局亮明）：顾晓梦（玲珑）、金生火（火攻）、王田香（审讯）、
  柒佰（神枪）、老枪（排查）、小翠（眼线）
- **暗置角色**（技能首次触发时当众翻开，并摸一张牌）：李宁玉（译电）、
  老鳖（城府）、白小年（转念）、吴志国（硬汉）、张司令（官威）、老鬼（迷踪）、
  黑玫瑰（夜行）、峨嵋峰（太极）、疤叔（遗言）、影子（尾随）

## 辅助功能

- **线索面板**：点击任意座位查看你对该玩家已掌握的情报——立场倾向推测、
  试探结果、拒收/传牌/烧毁等行为记录、你破译过的手牌信息
- **终局复盘**：对局结束后可展开全知视角时间线，按轮次回看每张情报的
  真实颜色与传递路径（阵营着色）
- **AI 推理**：AI 会利用公开行为推测身份——拒收明置情报、传黑牌对象、
  烧毁对象都会被记入"敌意/善意"档案；AI 前期还会偶尔收敌色情报伪装立场
- **移动端适配**：手机竖屏有专门布局，"记录"按钮展开日志抽屉
- **本地战绩**：胜负按阵营记入 localStorage，开始界面与结算页展示；
  "再来一局/重开"为软重置，不刷新页面
- **游戏百科**：开始界面与局内均可打开——全部角色技能（含拓展）、
  功能牌数量/时机/效果、身份与酱油任务一览，数据与游戏定义实时同步

## 拓展包《危情》（可选）

开始界面可开启，牌库从 81 张扩至 93 张：

- **威逼**×6：迫使一名玩家交给你一张手牌（由其选择）
- **利诱**×6：展示牌库顶两张，目标先选一张收入手牌，你得另一张

## 拓展包《绝密行动》（可选）

对应原作"让打酱油不再无关痛痒"的思路，强化第三阵营：

- 酱油任务池新增：**纵火狂**（累计烧毁三张黑情报）、**劫收专员**
  （靠【截获】收下两张情报）、**完美中立**（第六轮结束时存活且无红蓝情报）
- **耳目密报**：每名酱油开局得知一名随机玩家的真实身份

## 拓展包《绝密档案》（可选）

对应原作"+8 位角色"扩充，角色池 16 → 24：

- **公开**：报童（号外）、裁缝（量体）、车夫（快马）
- **暗置**：灰狐（匿影）、药剂师（解毒）、守夜人（守灵）、
  情妇（枕风）、老会计（清账）

三个拓展包在开始界面独立开关、可任意组合。

## 与原桌游的差异

为适配单机人机对战做了少量简化：角色技能取原作精神自拟了 8 个、
密电/文本方向均可自选、酱油任务为自拟的三选一、无手牌上限。

## 开发者

- **回归模式**：URL 加 `?autotest=N` 以全 AI 快速连打 N 局，结果写入
  `window.__allResults`
- **守恒看门狗**：引擎每回合校验全场恰为 81 张牌且无重复 id，
  异常会写入日志与 `window.__censusError`（防复制/丢牌类 bug）
- **场景测试组**：`node tests/battery.js`（需 Playwright + Chromium），
  覆盖技能结算、酱油任务、死亡流程、调包/截获链、牌库重洗与 30 局守恒
