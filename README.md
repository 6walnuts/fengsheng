# 风声 · 谍战桌游（网页版）

以经典国产谍战桌游《风声》（The Message）为蓝本的单机网页游戏：你 + 3~7 名 AI，
三大阵营身份暗置对抗。零依赖，单文件实现。

## 怎么玩

直接用浏览器打开 `index.html` 即可（无需服务器、无需联网）。

## 规则概要

### 阵营与胜利条件

| 阵营 | 胜利条件 |
|------|----------|
| 潜伏战线 | 任意一名潜伏玩家集齐 **3 张红色情报**，或**军情处全部出局** → 全体潜伏获胜 |
| 军情处 | 任意一名军情玩家集齐 **3 张蓝色情报**，或**潜伏战线全部出局** → 全体军情获胜 |
| 打酱油 | 完成角色牌上的**机密任务**，或**成为全场唯一幸存者** → 单独获胜 |

任何玩家收到 **3 张黑色情报**（假情报）立即出局，亮出身份并弃置所有牌。

基础牌库含**双色情报**（红黑×3、蓝黑×3，黑名单版规则）：同时计入两种
颜色；一张牌同时凑满制胜与三张黑时，**先判死亡、不能获胜**（官方裁定）。

**绝密任务印在角色牌上**（黑名单版规则）：身份为打酱油时，胜利条件即你
角色自带的任务。黑名单人物的任务含斩草除根/连根拔起（阵营全灭）、红色档案/
蓝色档案/大收藏家（收集）、红袖招/洁身自好（共同获胜）、职业操守（黑情报
杀人）等；归档自制角色沿用情报贩子/殉道者/收藏家等七种，详见游戏内百科。

### 回合流程

1. **摸牌**：摸两张牌（起手三张）
2. **出牌阶段（一）**：可使用【烧毁】【试探】【锁定】等功能牌
3. **传递情报**：必须从手牌选一张作为情报传出，传递方式由牌右上角印章决定：
   （传完后还有**出牌阶段（二）**）
   - **直达**：面朝下直接交给任意玩家，对方可接收或退回（退回则自己收下）
   - **密电**：面朝下沿所选方向从邻座依次传递，每人可接收或传给下家
   - **文本**：面朝上依次传递
   - 无人接收时由传出者自己收下

### 功能牌

完整黑名單牌库（喬桌遊考据）共 14 类功能牌：

| 牌 | 数量 | 效果 |
|----|----|------|
| 锁定 | 5 | 仅自己回合（出牌阶段一 / 传递宣告时）：指定一名玩家，其必须接收本回合情报（优先于调虎离山、转移） |
| 调虎离山 | 4 | 情报传递宣告时：指定一名玩家，其不能接收本次情报 |
| 截获 | 10 | 他人回合传递时直接拉到自己面前（后发先至，可连环） |
| 转移 | 4 | 情报到你面前时：转移到另一名玩家面前，其如同被锁定必须接收 |
| 破译 | 10 | 情报到你面前时：先猜颜色再查看；猜中可公开该情报并摸一张牌 |
| 调包 | 8 | 传递阶段：换入你的调包牌并**面朝上展示**，原情报弃入弃牌堆（公开） |
| 博弈 | 4 | 出牌阶段：将牌库顶一张牌放到一名玩家面前成为情报（致死算「亲手」） |
| 权衡 | 2 | 出牌阶段：弃掉全部手牌，重新抽取等量的牌 |
| 增援 | 2 | 出牌阶段：你有黑色情报时，抽「黑情报数+1」张牌 |
| 试探 | 10 | 指定一名玩家按真实身份执行牌上指令——**结果只有你与目标知道** |
| 真伪莫辨 | 3 | 翻开与存活人数等量的牌库牌，从使用者起每人轮流挑一张收为情报 |
| 烧毁 | 10 | 几乎随时可用：烧掉任意玩家情报区的一张黑色情报 |
| 识破 | 4 | 抵销最新一张功能牌的效果；识破亦可被识破（连锁）。传递本身与角色技能不可被识破 |
| 平信 | 5 | 无功能，仅作情报 |

牌库另含**双色情报**（红黑/蓝黑各 3）。传递分三个响应窗口（黑名单规则）：
**宣告时**（锁定/调虎离山/截获/烧毁）→ **到达面前时**（破译/转移/调包）→
**决定接收时**（不可用牌）。功能牌与蓝色角色技能都遵循「后发先至」的回应机制。

### 角色技能

默认使用喬桌遊考据的《风声黑名單》**25 名人物**（潜伏 10 + 公开 15，
含性别体系），每人三层技能：**●翻开技**（暗置时用）、**○公开技**（角色
公开时用）、**◎限制技**（每局一次、不可被回应）。每个座位有公开的谍报
代号（夜莺、灰鸽……）：

- **潜伏 10**：老鬼、浮萍、老枪、闪灵、黑玫瑰、峨嵋峰、老金、译电员、
  黄雀、钢铁特工K（开局暗置，触发●翻开技时当众翻开）
- **公开 15**：刀锋、戴笠、贝雷帽、礼服蒙面人、小马哥、柒佰、六姐、
  怪盗九九、小白、职业杀手、致命香水、情报处长、福尔摩斯、蝮蛇、大美女

开始界面「人物版本」可切换：

- **黑名單人物（默认·25人）**：上述喬桌遊考据人物，技能与机密任务逐条对表
- **归档（自制+旧黑名单）**：早期版本的 16 名自拟人物、8 名绝密档案角色，
  以及本作最初做的旧黑名单 12 人（技能为早期粗糙版），保留可选

## 辅助功能

- **线索面板**：点击任意座位查看你对该玩家已掌握的情报——立场倾向推测、
  你亲自试探所得（试探结果仅当事双方可见）、拒收/传牌/烧毁等行为记录
- **身份推理引擎**：试探/对枪/耳目所得写入每名玩家的**私有认知**，并结合
  公开的阵营人数配置自动推理——排除两阵营即确认第三个；某阵营名额被
  确认者占满则其余人自动排除；未排除者恰好补满名额时全部自动确认
- **终局复盘**：对局结束后可展开全知视角时间线，按轮次回看每张情报的
  真实颜色与传递路径（阵营着色）
- **AI 推理**：AI 会利用公开行为推测身份——拒收明置情报、传黑牌对象、
  烧毁对象都会被记入"敌意/善意"档案；AI 前期还会偶尔收敌色情报伪装立场
- **移动端适配**：手机竖屏有专门布局，"记录"按钮展开日志抽屉
- **本地战绩**：胜负按阵营记入 localStorage，开始界面与结算页展示；
  "再来一局/重开"为软重置，不刷新页面
- **游戏百科**：开始界面与局内均可打开——全部角色技能（含拓展）、
  功能牌数量/时机/效果、身份与酱油任务一览，数据与游戏定义实时同步
- **点击选目标**：所有指向性操作（烧毁/试探/直达/锁定/调虎离山/威逼
  等）直接点击场上高亮座位选择目标，不再从对话框列表挑名字
- **存档续玩**：每回合自动存档（localStorage），关掉页面下次打开
  可"继续上局"，AI 局面、身份、线索、复盘记录完整还原
- **音乐与音效**：Web Audio 全程序化合成（零音频文件）——D 小调谍战
  氛围 BGM（低音持续+夜雨底噪+稀疏拨弦回声）与动作音效（摸牌/传递/
  收情报/黑情报/截获/锁定/死亡/胜利等），顶栏 🔊 一键静音并记忆偏好

## 牌库版本（二选一）

开始界面独立一行开关：

- **黑名單完整（默认）**：喬桌遊考据的 81 张牌库——双色情报 + 上表 14 类
  功能牌（含转移/博弈/权衡/增援），三窗口传递与出牌阶段（二）
- **经典简化**：81 张纯色牌库（截获/破译/调包/烧毁/试探/平信），
  单窗口传递、单出牌阶段

> 注：早期做过的「千智新版牌库」（维基无双色印次）与自加的【退回】【离间】
> 已并入 / 移除——喬桌遊黑名單的真正配置是双色 + 转移 + 真伪莫辨并存，
> 且额外含博弈/权衡/增援。

## 拓展包《危情》（可选）

开始界面可开启，牌库从 81 张扩至 93 张：

- **威逼**×6：迫使一名玩家交给你一张手牌（由其选择）
- **利诱**×6：展示牌库顶两张，目标先选一张收入手牌，你得另一张

## 拓展包《绝密行动》（可选）

对应原作"让打酱油不再无关痛痒"的思路，强化第三阵营：

- 酱油任务池新增：**纵火狂**（累计烧毁三张黑情报）、**劫收专员**
  （靠【截获】收下两张情报）、**完美中立**（第六轮结束时存活且无红蓝情报）
- **耳目密报**：每名酱油开局得知一名随机玩家的真实身份

## 拓展包《绝密档案》（可选）

对应原作"+8 位角色"扩充，角色池 16 → 24：

- **公开**：报童（号外）、裁缝（量体）、车夫（快马）
- **暗置**：灰狐（匿影）、药剂师（解毒）、守夜人（守灵）、
  情妇（枕风）、老会计（清账）

三个拓展包在开始界面独立开关、可任意组合。

## 与原桌游的差异

为适配单机人机对战做了少量简化：密电/文本方向均可自选、无手牌上限、
柒佰【义气】的共胜对象自动选取；归档自制角色与其三选一酱油任务为
早期版本自拟内容，可在开始界面切换。

## 开发者

- **回归模式**：URL 加 `?autotest=N` 以全 AI 快速连打 N 局，结果写入
  `window.__allResults`
- **守恒看门狗**：引擎每回合校验全场恰为 81 张牌且无重复 id，
  异常会写入日志与 `window.__censusError`（防复制/丢牌类 bug）
- **场景测试组**：`node tests/battery.js`（需 Playwright + Chromium），
  覆盖技能结算、酱油任务、死亡流程、调包/截获链、牌库重洗与 30 局守恒
